A post-hoc, global, model-agnostic explainer for machine-learning models trained on spectra. SMX explains a classifier in terms of spectral zones, ranks them with a graph of logical predicates, and draws each decision threshold back onto the spectrum in its original units.

How it works

  1. Spectra & zonesexpert-defined or detected cuts
  2. Zone scoresone PCA score per zone
  3. Predicatesquantile rules: zone ≤ t, zone > t
  4. Bagged perturbationperturb a zone, query the model
  5. Predicate graphranked by LRC
  6. Threshold spectraback to natural units

Each zone is summarised by its first principal component, which keeps the continuity and collinearity of neighbouring variables. Quantiles of that score give the predicates. Within each stochastic bag of samples, SMX perturbs the zone behind every predicate and measures how much the model's prediction moves. Ordering the predicates by that impact yields a path, and the paths of all bags and repetitions merge into one weighted, directed graph. Its Local Reaching Centrality ranks the predicates, and since PCA is invertible, each threshold maps back to a spectrum you can overlay on your own measurements.

What you get

Zone ranking

Spectral zones ordered by the Local Reaching Centrality of their best predicate: which regions of the spectrum drive the model's decisions.

Threshold spectra

Each predicate's decision boundary reconstructed in the original spectral domain, ready to compare against measured spectra.

Predicate graph

The directed graph of predicates, weighted by perturbation impact (and optionally by the variance each zone explains), that ends in class nodes.

Faithfulness

Progressive masking of the top-ranked zones, compared with random rankings, checks that the explanation reflects what the model actually uses.

All three figures above are SMX's own Plotly output, exported to HTML: hover, zoom and toggle the legend entries. See the plotting guide.

Get started

1 Install the package

$ pip install spectral-model-explainer

The core needs only NumPy, pandas, SciPy, scikit-learn and NetworkX.

2 Add plotting (optional)

$ pip install "spectral-model-explainer[plotting]"

Adds Plotly for the interactive figures. Static PNG, SVG or PDF export also needs kaleido.

3 Explain a spectral classifier

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
from smx import SMX, generate_synthetic_spectral_data

# two classes that differ in one peak each (class B at 50, class A at 700)
df = generate_synthetic_spectral_data([
    {"name": "A", "n_samples": 120, "peaks": [250, 380, 550, 700, 850]},
    {"name": "B", "n_samples": 120, "peaks": [50, 250, 380, 550, 850]},
], n_points=500, x_min=1, x_max=1000, seed=0)
X, y = df.drop(columns="Class"), df["Class"]

# SMX expects a 0..n-1 row index on the calibration set
X_cal, X_test, y_cal, y_test = (part.reset_index(drop=True) for part in train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42))
X_cal_prep = X_cal - X_cal.mean()  # mean-centring
model = SVC(probability=True, random_state=42).fit(X_cal_prep, y_cal)

smx = SMX(
    spectral_cuts=[("F1", 1, 100), ("F2", 200, 300), ("F3", 330, 430),
                   ("F4", 500, 600), ("F5", 660, 750), ("F6", 815, 890)],
    quantiles=[0.25, 0.5, 0.75],
    estimator=model,
    perturbation_metric="probability_shift",
)
p_class_a = model.predict_proba(X_cal_prep)[:, 0]
smx.fit(X_cal_prep, pd.Series(p_class_a), X_cal_natural=X_cal)

print(smx.lrc_summed_unique_.head())         # zones ranked by LRC
smx.plot_zone_ranking_over_spectrum("zone_ranking.html")

F1 and F5 come out on top: the two zones where the classes differ. The full quickstart script adds background zones, faithfulness and threshold-spectrum plots.
